
# LinkQR AI - Enterprise Smart QR Ecosystem

This project is a high-performance Next.js 14 application powered by Firebase and Google AI (Genkit).

## 🚀 Post-Studio Management (After March 27th)

Since Firebase Studio is closing, follow these steps to continue development with AI assistance:

1. **GitHub Setup**: 
   - Initialize a git repository in the root: `git init`
   - Push your code to a new GitHub repository.
2. **AI Development Tools**:
   - **Cursor IDE**: Highly recommended. It's a local code editor that lets you update code using AI just like this Studio.
   - **Bolt.new**: Web-based AI builder for full-stack apps.
3. **Firebase Console**: 
   - Go to [Firebase Console](https://console.firebase.google.com/)
   - Link your GitHub repository to **App Hosting**.
4. **Local Development**:
   - Install dependencies: `npm install`
   - Run dev server: `npm run dev`
   - To deploy: Push to your linked GitHub branch (main).

## Key Features
- **3-Column Studio Builder**: Advanced modular page builder for smart landing pages.
- **AI Magic Studio**: Generative QR design and AI Copywriting via Gemini.
- **Conversion Engine**: FOMO Timers, UPI Payments, and Lead Capture.
- **Enterprise CRM**: Real-time Lead and Sales management.
- **BI Hub**: 10 levels of business intelligence and bot protection.

## Environment Secrets
Ensure the following are set in your Firebase App Hosting environment variables:
- `FIREBASE_SERVICE_ACCOUNT_KEY`: (Service account JSON for Admin SDK)
- `GEMINI_API_KEY`: (Google AI Studio Key for GenAI features)
- `GMAIL_USER` / `GMAIL_APP_PASSWORD`: (For automated lead emails)
